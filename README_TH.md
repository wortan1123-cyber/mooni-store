# MOONI ร้านค้าออนไลน์ + ระบบหลังบ้าน

แพ็กเกจนี้มีหน้าร้าน, ตะกร้า, ฟอร์มสั่งซื้อ, ระบบหลังบ้านล็อกอิน, จัดการสินค้า/สต็อก, รายการคำสั่งซื้อและสถานะ, และ schema ฐานข้อมูล Supabase

## ไฟล์ในแพ็กเกจ
- `index.html`, `style.css`, `store.js`: หน้าร้าน
- `admin.html`, `admin.js`: หลังบ้าน
- `config.js`: ค่าตั้งค่า Supabase และข้อมูลร้าน/บัญชีธนาคาร
- `supabase/schema.sql`: ตารางและ Row Level Security policies

## ตั้งค่า backend ฟรีด้วย Supabase
1. สร้างโปรเจกต์ที่ https://supabase.com/ (แพ็กเกจฟรีมีข้อจำกัด/อาจเปลี่ยนแปลงได้)
2. ไปที่ SQL Editor แล้วรันไฟล์ `supabase/schema.sql` ทั้งไฟล์
3. ไปที่ Project Settings / API แล้วคัดลอก Project URL และ anon/publishable key มาใส่ใน `config.js` ช่อง `SUPABASE_URL` และ `SUPABASE_ANON_KEY` เท่านั้น **ห้ามใส่ service_role/secret key ในไฟล์เว็บ**
4. ใน Authentication > Users สร้างบัญชีเจ้าของร้านด้วยอีเมลและรหัสผ่านที่ปลอดภัย
5. คัดลอก UUID ของบัญชีจากหน้า Users แล้วไป SQL Editor รันคำสั่งนี้ โดยแทน UUID:
   `update public.profiles set role='admin' where id='UUID-ของบัญชีเจ้าของร้าน';`
6. ไปที่ `config.js` กรอกชื่อธนาคาร ชื่อบัญชี เลขบัญชีร้าน อีเมล และลิงก์ช่องทางติดต่อจริง
7. ทดสอบบนเครื่องตัวเองผ่าน local server (เช่น VS Code Live Server) ก่อนเผยแพร่ อย่าเปิด `index.html` ด้วย file:// หากต้องการเชื่อม Supabase อย่างเชื่อถือได้

## เผยแพร่ URL ฟรีด้วย Netlify
1. เปิด https://app.netlify.com/ และสมัคร/เข้าสู่ระบบ
2. อัปโหลดโฟลเดอร์นี้โดยให้ `index.html`, `admin.html`, `config.js`, `store.js`, `admin.js`, `style.css` อยู่ที่รากโฟลเดอร์ (อย่าอัปโหลดแค่ไฟล์ ZIP โดยไม่แตกไฟล์)
3. Netlify จะให้ URL `https://ชื่อเว็บ.netlify.app` โดยอัตโนมัติ; หลังแก้ไฟล์ให้อัปโหลดใหม่หรือเชื่อม Git repository เพื่อ deploy อัตโนมัติ
4. ทดสอบ URL หน้าร้าน และเพิ่ม `/admin.html` เพื่อเข้าสู่ระบบผู้ดูแล

## การใช้งาน
- หน้าร้าน: ลูกค้าเลือกสินค้า เพิ่มตะกร้า กรอกชื่อ/โทรศัพท์/ที่อยู่ แล้วส่งคำสั่งซื้อ
- หลังบ้าน: เข้าผ่าน `/admin.html`; แอดมินเพิ่ม/แก้ไขสินค้า เปิดปิดสินค้า เปลี่ยนสต็อก และอัปเดตสถานะคำสั่งซื้อ
- การโอนเงิน: หลังสั่งซื้อ ระบบจะแสดงรายละเอียดบัญชีที่ตั้งไว้ใน `config.js`; แอดมินต้องตรวจสอบยอดเงินจริงจากธนาคารก่อนเปลี่ยนสถานะเป็น “ชำระแล้ว”

## ข้อจำกัดสำคัญก่อนเปิดขายจริง
- นี่คือ starter store สำหรับนำไปติดตั้ง ไม่ใช่ระบบ production ที่ผ่าน audit ความปลอดภัยแล้ว
- นโยบาย public checkout อนุญาตให้ผู้เยี่ยมชมสร้างคำสั่งซื้อได้ แต่การตรวจสอบราคา/สต็อกฝั่งเซิร์ฟเวอร์และการป้องกัน spam/rate limit ยังต้องเพิ่มก่อนเปิดรับออเดอร์ปริมาณมาก
- สินค้า/ยอดรวมที่ส่งจาก browser สามารถถูกดัดแปลงได้ จึงควรยืนยันราคาและสต็อกก่อนรับชำระเงินจริง; สำหรับ production ควรย้ายการสร้างออเดอร์ไป Edge Function ที่คำนวณราคาใหม่จากฐานข้อมูล
- ยังไม่มีการอัปโหลดสลิป, อีเมลแจ้งเตือนอัตโนมัติ, ระบบขนส่ง, หรือ gateway ชำระเงิน
- ควรเพิ่ม CAPTCHA/rate limiting, privacy policy, เงื่อนไขการขาย, การสำรองข้อมูล และทดสอบ RLS ก่อนใช้กับข้อมูลลูกค้าจริง
- URL ของ Netlify เป็น public; อย่าใส่รหัสผ่านหรือข้อมูลลับลงในไฟล์หน้าเว็บ
